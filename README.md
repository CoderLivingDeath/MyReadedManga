# MyReadedManga

Obsidian vault для отслеживания прочитанной манги с заметками и личными рецензиями.

## Содержимое

- **Перепись манги.md** — список манги с ссылками на источник и заметками/рецензиями на русском языке.

## Как использовать

1. Откройте папку проекта как [Obsidian vault](https://obsidian.md/).
2. Открывайте `Перепись манги.md` и пополняйте список прочитанной манги.

## Структура записей

Каждая запись включает:

- Название манги со ссылкой на источник (Remanga и др.).
- Личное мнение/рецензия (если есть).

## Лицензия

Содержимое репозитория — личные заметки.
